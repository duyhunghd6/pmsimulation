# Glossary

## Agent

An AI coding collaborator operating inside the repository.

## Harness

The repo-level operating system that tells humans and agents how to turn intent into safe product changes.

## Product Contract

The current expected behavior of the product. Product docs plus executable tests become the living contract once implementation exists.

## Story Packet

A story-sized work file or folder that describes the product contract, affected docs, design notes, and validation expectations for a feature.

## Feature Intake

The classification step that turns a prompt into tiny, normal, or high-risk work before implementation begins.

## Harness Delta

A documentation, template, validation, backlog, or decision update that makes future agent work safer or easier.

## Product Delta

A product-facing change such as code, tests, API shape, data model, or product documentation.

## Asset Pyramid

The portfolio structure taught by the product: Base for safety, Core for yield, and Apex for alpha.

## TARA Matrix

The rebalancing method taught by the product: Transfer, Avoid, Reduce, Accept.

## Pedagogical Deterministic Engine

The curriculum-driven simulation engine that uses scripted macro scenarios and deterministic calculations instead of random market returns.

## Macro Narrative

A scripted monthly scenario row containing macro indicators and news used to drive deterministic simulation outcomes.

## God Mode

Instructor-only visibility into all student portfolios and class-wide analytics for facilitation and debriefing.

## Crowded-Trade Liquidity Penalty

A simulated slippage penalty applied when classroom order flow clusters on the same sell action.
