# Documentation Map

This directory holds the project harness and the product contract derived from the accepted Apex Alpha PRD.

## Main Files

- `HARNESS.md`: how humans and agents collaborate.
- `FEATURE_INTAKE.md`: how prompts become tiny, normal, or high-risk work.
- `ARCHITECTURE.md`: architecture discovery, selected stack direction, and boundary rules.
- `TEST_MATRIX.md`: living map of behavior to proof.
- `HARNESS_BACKLOG.md`: improvements discovered while working.
- `GLOSSARY.md`: shared terms.

## Folders

- `prd/`: original PRD source material.
- `product/`: current product truth derived from the accepted spec.
- `stories/`: feature packets, spec intake, and backlog.
- `decisions/`: durable decisions and tradeoffs.
- `templates/`: reusable spec-intake, story, plan, decision, and validation formats.

## Current State

Harness v0 has ingested `docs/prd/PRD-01.md` into `SPEC.md`, product docs, candidate epics, validation expectations, and an architecture decision.

No application code, tests, CI, package scripts, database migrations, or deployment automation exist yet.
